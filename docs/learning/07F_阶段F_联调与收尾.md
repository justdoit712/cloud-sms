## 步骤 5.1 · 全量构建 + 依赖服务准备

**目标**：所有模块一次构建通过，全部中间件就绪。

**前置条件**：阶段 A~E 全部完成。

**操作清单**

1. 全量构建（不允许 skip）：

```powershell
cd $ROOT\backend
mvn clean install
```

2. 中间件清单与版本（docs 中间件基线）：Nacos 2.3.x、MySQL 8.0.x（库 `duanxin_pingtai`，数据从旧库导出导入）、Redis 7.x、RabbitMQ 3.12+（**必须装 delayed 插件**：`rabbitmq-plugins enable rabbitmq_delayed_message_exchange`）、Elasticsearch 8.x（开安全认证，创建 elastic 账号）、xxl-job-admin 2.4.x、CMPP 模拟器（`模拟cmpp-server.zip`，监听 127.0.0.1:7890）。
3. Nacos 配置：为 9 个服务建 `{app}-dev.yml`（按旧项目配置迁移，删掉 shiro/旧数据源项，新增 `sa-token.*`、`cmpp.*`、`cmpp.pool.*`）。
4. 前端：`cd $ROOT\frontend && npm run build`；部署方式（Nginx 静态托管 + 反代，或单独域名 + CORS）按 PROGRESS 待确认项决策后执行。

**验收标准**

- [ ] `mvn clean install` 全绿（含全部测试）
- [ ] 所有中间件健康检查通过（Nacos 控制台、`redis-cli ping`、`rabbitmqctl status`、ES `/_cluster/health`、xxl-job 控制台登录、CMPP 模拟器端口监听）

**常见坑**：RabbitMQ 未装 delayed 插件 → push 模块启动声明交换机即失败；ES 8 安全认证未开账号 → search 启动连接 401；Nacos 配置缺项 → 各服务启动失败（对照旧配置逐项迁移，不漏 `gateway.sendtopic` 等关键项）。

**回退**：本步无代码改动，环境问题就地修复。

**提交产出**：（如有配置脚本/启动脚本）`chore(ops): 中间件准备脚本与 Nacos 配置清单`。

## 步骤 5.2 · 逐服务启动 + 主链路冒烟

**目标**：证明重构后系统端到端可用。

**启动顺序**（README 约定）：

```text
1 beacon-cache → 2 beacon-strategy → 3 beacon-search → 4 beacon-push
→ 5 CMPP 模拟器 → 6 beacon-smsgateway → 7 beacon-api → 8 beacon-webmaster → 9 beacon-monitor
```

**冒烟清单（逐条打勾）**

- [ ] `POST /sms/single_send`（真实 apikey+签名短信）→ 返回 `{uid,sid}`
- [ ] 策略链路日志出现过滤器顺序输出；无敏感词拦截
- [ ] 网关日志出现 CMPP Submit → SubmitResp（result=0）
- [ ] ES `sms_submit_log_{year}` 出现文档（reportState=0）
- [ ] 模拟器回 Deliver（DELIVRD）→ 10s 后 ES reportState=1
- [ ] 客户回调 URL 收到推送（若开启 isCallback）
- [ ] webmaster 登录 → 代发短信 → 检索/统计页正常
- [ ] monitor 在 xxl-job 手动触发两任务回执 200
- [ ] 前端全页面点检（登录/菜单/客户/通道/策略链/模板/图表）

**常见坑**：启动顺序错 → 队列未声明/监听器反复重试（严格按序）；CMPP 模拟器未起 → smsgateway 启动即失败（`initMethod=start` 阻塞，业务缺陷后处理）；跨年索引/时区问题在冒烟期以"当前年"为准记录，不修。

**回退**：单项冒烟失败 → 回对应分册找该模块的"常见坑"；仍无法解决 → 记录到 PROGRESS 阻塞区，不阻塞其它项。

**提交产出**：无代码提交（冒烟属验证）。
