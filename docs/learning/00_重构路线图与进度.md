## 关键决策记录

1. **新目录独立重构**：`D:\Code\project\cloud-sms`（前后端分离：backend/ + frontend/），旧项目 `beacon-cloud` 保持不动，随时对照。
2. **版本号升为 2.0.0-SNAPSHOT**（重构启动时执行），所有模块对 beacon-common 的依赖引用同步升级。
3. **Hippo4j 暂缓**：Central 无 2.x/boot3 版本，网关暂以标准 ThreadPoolExecutor 等价替换，笔记 05 记录回归方案。
4. **业务缺陷不修**：分析报告（`analysis/`）里的 38 项风险问题留待升级完成后按优先级处理。
5. **前期调研发现（已记录，供重构时参考）**：
   - `javax` → `jakarta` 迁移点共 35 处（annotation/validation/servlet 三类；`javax.crypto`、`javax.mail`、`javax.imageio` 保持不变）。
   - kaptcha 0.0.9 的 servlet-api 依赖为 provided，不会带入 Boot 3 类路径冲突。
   - beacon-common 旧 pom 已引用 `jakarta.annotation-api`，但源码仍 import `javax.annotation`（JDK 8 内置），JDK 17 下必须改 import。
   - 测试代码用 JUnit 4（`org.junit.*`），Boot 3 的 starter-test 只有 JUnit 5，需迁移。
