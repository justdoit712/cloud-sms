## 附 B · 跨 PC 执行提醒

1. 每步结束更新 `PROGRESS.md` 并提交，换机先读 PROGRESS。
2. 阶段 C/D 内部并行时，不同 PC 分工需在 PROGRESS 登记"谁在做哪个模块"。
3. 所有编译命令在 PowerShell 下带 `-D` 参数用引号包裹（历史教训：未加引号导致参数被截断）。
4. 依赖中间件的本地环境差异（各 PC 的 Nacos/Redis/ES 地址不同）一律走 `${...}` 配置 + Nacos，**禁止改代码适配本机**。
