## 步骤 3.1 · beacon-smsgateway

**目标**：Netty 升级 + 线程池替换 hippo4j + CMPP 参数外置。

**前置条件**：1.1 完成。

**操作清单**

1. `pom.xml`：删 `hippo4j-spring-boot-starter`；`netty-all` 版本删除（父 POM 4.1.138.Final）。
2. `ThreadPoolConfig` 重写（Bean 名不变）：

```java
@Configuration
public class ThreadPoolConfig {
    @Bean("cmppSubmitPool")
    public ThreadPoolExecutor cmppSubmitPool(
            @Value("${cmpp.pool.submit-core:4}") int core,
            @Value("${cmpp.pool.submit-max:16}") int max,
            @Value("${cmpp.pool.submit-queue:2000}") int queue) {
        return new ThreadPoolExecutor(core, max, 60, TimeUnit.SECONDS,
                new ArrayBlockingQueue<>(queue),
                threadFactory("cmpp-submit"),
                new ThreadPoolExecutor.CallerRunsPolicy());
    }
    // cmppDeliverPool 同构（cmpp-deliver / 默认 core=2 max=8 queue=2000）

    private static ThreadFactory threadFactory(String prefix) {
        return r -> { Thread t = new Thread(r); t.setName(prefix + "-" + t.getId()); t.setDaemon(false); return t; };
    }
}
```

3. `NettyStartCMPP` 参数外置：

```java
@ConfigurationProperties(prefix = "cmpp")
public record CmppGatewayProperties(String host, int port, String serviceId, String pwd) {}

@Configuration
@EnableConfigurationProperties(CmppGatewayProperties.class)
public class NettyStartCMPP {
    @Bean(initMethod = "start")
    public NettyClient nettyClient(CmppGatewayProperties p) {
        return new NettyClient(p.host(), p.port(), p.serviceId(), p.pwd());
    }
}
```

4. `bootstrap.yml` 增加 `cmpp.host/port/service-id/pwd`（值沿用 127.0.0.1/7890/cz/123，Nacos 可覆盖）与 `cmpp.pool.*` 默认值。
5. `SmsGatewayStarterApp`：删 `@EnableDynamicThreadPool`。
6. `TestController`：0.3 已换 jakarta 注解。
7. netty4 包 7 个类：Netty 4.1 线 API 稳定，预计零改动（编译验证）。

**执行命令**：`mvn -pl beacon-smsgateway -am install`

**验收标准**

- [ ] 测试/编译全绿
- [ ] `cmppSubmitPool`/`cmppDeliverPool` Bean 名不变（`SpringUtil.getBeanByName` 取用不动）
- [ ] （阶段 F）连模拟 CMPP Server（127.0.0.1:7890）提交-应答-回执全链路通

**常见坑**：`ThreadFactoryBuilder` 是 guava 的——**本项目无 guava 依赖**，用 JDK lambda 写法（见模板）；hippo4j 删掉后 `ThreadPoolBuilder` import 必须清干净。

**回退 / 提交**：`git checkout -- beacon-smsgateway` / `refactor(gateway): Netty 4.1.138 + 标准线程池替换 hippo4j + CMPP 参数外置`。
